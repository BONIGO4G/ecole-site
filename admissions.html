Demande d’admission

Remplissez le formulaire ci-dessous. Un accusé de réception sera envoyé au parent via l’email saisi, et une notification sera transmise à l’équipe JBS2.

En envoyant ce formulaire, vous acceptez que vos informations soient utilisées pour traiter la demande d’inscription.
Lire la FAQ →

Ce que vous recevrez

  • Accusé de réception au parent (email saisi)
  • Notification à l’équipe JBS2+ pour traitement
  • Redirection avec message de succès

Configuration Netlify (à faire)

  1. Netlify → Site settings → Forms → inscription
  2. Notification : envoi à yeouehieboniface@gmail.com
  3. Responder (email parent) :
    {{ email }}
  4. Redirect URL :
    admissions.html?ok=1

Si Netlify utilise une autre syntaxe de variable, vérifiez l’aperçu “Templates/Variables” dans l’onglet Forms.
